# Buyer Marketplace App

A starter monorepo for a marketplace app focused on helping sellers discover and connect with buyers. This repo includes:

- Web app for listing products and buyer discovery
- API for marketplace data and leads
- Mobile app shell for iOS and Android
- Shared product and buyer concept foundation for a B2B + B2C marketplace

## Project structure

- `apps/web` — Next.js storefront and lead discovery experience
- `apps/api` — Express API for catalog and buyer data
- `apps/mobile` — Expo React Native app shell

## Quick start

```bash
npm install
npm run dev:web
npm run dev:api
```

For the mobile app:

```bash
npm run dev:mobile
```

## Business idea

This app helps sellers market and expose products to the right buyers using filters, lead forms, category matching, and buyer-focused product discovery.

## Roadmap

- Product catalog and listing management
- Buyer segmentation and category targeting
- Search, filters, and product recommendations
- Lead capture and inquiry flows
- Seller dashboards and order management
- Mobile-first purchase and communication experience
